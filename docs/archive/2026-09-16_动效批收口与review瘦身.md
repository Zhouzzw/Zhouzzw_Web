### 💡 关键发现

- #tag: css — **交互效果（hover 类）必须 CSS 媒体查询 + JS matchMedia 同口径门控**，且只能靠**真实 CDP 鼠标事件**验证（合成 PointerEvent 不触发 `:hover`）；减动效仿真必须走 CDP `Emulation.setEmulatedMedia`，页面内 stub matchMedia 无效
- #tag: 性能 — 指针跟随高光用「rAF 节流 + CSS 变量 + `::after` 径向渐变」实现零布局成本（`--spot-x/--spot-y` 需先在 `:root` 声明，红线 #2）
- #tag: 视觉验证 — **hero 是 `svh` 垂直居中，内容增减被视口高度吸收**：B3 加一行、字号放大一档，页高基准（15640/14332）均零变化；像素差分 + bbox 与元素矩形对账是「局部装饰效果」最硬的证据形式
