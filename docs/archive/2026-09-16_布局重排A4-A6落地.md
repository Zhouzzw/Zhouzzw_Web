### 💡 关键发现

- #tag: css — grid 容器「加列 + 定点占用」是「两元素并排」的纯 CSS 解：容器从 2 列改 3 列，两个元素分别固定到 `2/3`、`3/4` 列，其余元素保持 `2 / -1` 跨列不受影响
