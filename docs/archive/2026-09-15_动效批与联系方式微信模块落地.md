### 🧭 决策

| 决策 | 结论 |
|------|------|
| 联系方式形态 | 微信号**明文常显**是底线（读屏/复制/无 JS 都要能拿到），二维码只是补充；15 位数字手输必错 → 复制是刚需 |

### 💡 关键发现

- #tag: 视觉验证 — 合成事件测不出依赖 user activation 的 API（剪贴板），须用 CDP 真实鼠标/键盘事件；读异步结果前要等一拍；无头页面默认不聚焦，需 `Emulation.setFocusEmulationEnabled`
- #tag: 视觉验证 — `Page.captureScreenshot` 的 `clip` 是**页面坐标**，页面滚动后要加 `scrollY`
- #tag: css — 同特异性规则谁生效只看源码顺序；被复用组件的覆盖样式要提升特异性
- #tag: 性能 — Vite 默认把 <4KB 资源内联为 data URI，小图不必再想懒加载
- #tag: design — 纯装饰动效先问再做，被否后记进 TODO 已否决清单防重提
