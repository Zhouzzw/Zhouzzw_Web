### 💡 关键发现

- #tag: 视觉验证 — 网页渲染核验可行路径：`google-chrome --headless=new --virtual-time-budget=8000 --window-size=W,H` + 临时 CSS 隔离目标 section；**验证后必须重新 `npm run build`** —— `dist/` 未被 git 跟踪，`git checkout` 无法还原被改写的构建产物
