### 💡 关键发现

- #tag: css — 键盘可达性只能靠**真实 CDP 键事件**验证：`<button>` 的 Enter/Space 激活发生在 keypress，只发 keyDown 不触发 click
- #tag: css — 内联 > 类：`.section--dark { background }` 被 HTML 内联 `#242423` 静默压制整轮 → **布局重排前必须先清内联**
- #tag: 性能 — 生产 vs dev 的差距几乎全在文本资源（js 250.8→2.9 KB）；**图片 1118 KB 与字体 1082 KB 字节不变，优化这两项才有意义**
- #tag: docs — review-v3 的 I14 判据有误：Geist 已在 `index.html` 引用，本沙箱 jsdelivr 不可达才是根因
- #tag: 视觉验证 — `git worktree` 检出旧 commit 起第二个 dev server 做**同 run 对照**，是「清理 / 重构类改动零位移」最可靠的验证手段
