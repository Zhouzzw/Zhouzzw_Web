# 运维手册 — zhouzzw.online

> 面向站点所有者。目标：**任何问题都能在 5 分钟内定位**。最后更新 2026-09-22。
> 改代码前先读 `CLAUDE.md`（设计/交互规范 + 工程红线）。

## 一、上线结构（一句话）

用户输入网址 → **DNS**（Cloudflare）回答"去哪" → 浏览器连上**最近的 CF 边缘节点** → 节点把 **Cloudflare Pages 上的静态文件**返回，全程 HTTPS。

| 层 | 提供方 | 关键值 | 费用 |
|----|--------|--------|------|
| 域名注册 | **阿里云** | `zhouzzw.online`（.online） | 见第四节 |
| DNS 解析 | **Cloudflare** | NS = `april` / `yoxall.ns.cloudflare.com` | ¥0 |
| 托管 + CDN + HTTPS | **Cloudflare Pages** | 项目 `zhouzzw-web`，生产分支 `main` | ¥0 |

> **没有服务器**：站点是纯静态文件（35 个 / ~89MB，含 8 段视频），存在 Cloudflare 网络上、全球就近分发。
> 域名在哪注册 ≠ 解析在哪做 —— 注册商始终是阿里云，只是把"解析托管"交给了 Cloudflare（改 NS 的含义）。

## 三、日常操作

**更新网站（唯一高频操作）**
```bash
cd /home/qskj-2/personal_web/Zhouzzw_Web
export CLOUDFLARE_API_TOKEN="$(cat ~/.cf_token)"
npm run deploy:cf      # 构建 + 上传，约 30 秒；1 分钟内全球生效
```
> 脚本已带 `--branch=main` → 直接更新**生产环境**（`zhouzzw.online` 与 `zhouzzw-web.pages.dev` 同时生效）。
> **部署后自检**：`curl -s "https://zhouzzw.online/?v=$(date +%s)" | grep -c "<刚改的特征串>"`（≠ 0 即已生效）；或看 CF → Deployments 最新一条状态。

**本地预览**
```bash
npm run dev            # http://localhost:5173/Zhouzzw_Web/
```

**发布新视频 / 大图**
1. 先转码（**单文件必须 < 25 MiB**，否则部署被拒）：
   `ffmpeg -y -i in.mp4 -c:v libx264 -crf 29 -preset medium -movflags +faststart -c:a aac -b:a 128k out.mp4`
   （1080p30 文本类素材 CRF 29 ≈ 1.2 Mbps；仍超限就升到 CRF 30–31 或降分辨率）
2. 放入 `assets/videos/`，在 `index.html` 挂载
3. `npm run deploy:cf`

### 域名续费与防忘（唯一会产生后果的运维项）

| 阶段 | 时间 | 后果 | 处理 |
|------|------|------|------|
| 提醒期 | 到期前 30 天起 | 阿里云邮件 / 短信提醒 | ✅ 此时续最省心 |
| **宽限期** | 到期后 0–30 天 | **DNS 停止解析 → 全站打不开**（CF 侧完好，续费即恢复） | 仍可按**正常价**续费 |
| 赎回期 | 到期后 30–60 天 | 域名锁死 | 需付**赎回费**（数百元）**+ 续费价** |
| 已删除 | 60 天后 | 释放回公共池，可能被抢注 | 可能永远拿不回：旧链接全部失效 / 指向他人 |

**防忘三件套**

3. 确认阿里云账号**手机 + 邮箱**可用（提醒发这里）

## 六、故障排查（按现象查）

| 现象 | 先查什么 | 处理 |
|------|----------|------|
| 整站打不开 | DoH 查 NS：`curl 'https://cloudflare-dns.com/dns-query?name=zhouzzw.online&type=NS' -H 'accept: application/dns-json'` | 多为**域名过期** → 阿里云控制台续费；或 NS 被误改 |
| `zhouzzw.online` 打不开但 `pages.dev` 正常 | CF → Pages → Custom domains 状态 | 证书/路由未激活 → 删掉重新添加域名 |
| 某图/视频打不开 | **看 `content_type`**（可能是 SPA 回退的 `200 + text/html`） | 文件名或构建 hash 变了 → 检查构建产物与引用 |
| 部署报「项目不存在」 | 等 10–15 秒重试 | CF API 最终一致性延迟（已知现象） |
| 部署报文件超限 | 单文件是否 > 25 MiB | 用 ffmpeg 转码（CRF 29，命令见第三节「发布新视频 / 大图」） |
| 部署成功但线上没变 | 是否落到预览环境（`<分支>.zhouzzw-web.pages.dev`） | 用仓库里的 `npm run deploy:cf`（已内置 `--branch=main`） |

**通用工具**：浏览器 F12 → Network（只看状态码不够，要配合 content-type）；CF dashboard → Deployments（部署历史 + 回滚）。

## 八、概念速查

| 概念 | 一句话 |
|------|--------|
| 域名 | 网站的门牌号（在阿里云"租"的，按年续） |
| 注册商 / 注册局 | 注册商 = 阿里云（卖域名的店）；注册局 = `.online` 的管理机构 |
| DNS | 互联网的"电话簿"：把域名翻译成 IP |
| NS 记录 | "这本电话簿由谁维护" —— 现为 Cloudflare（`april` / `yoxall`） |
| A / CNAME 记录 | 域名 → IP / 域名 → 另一个域名（Pages 用 CNAME：`@` 与 `www` → `zhouzzw-web.pages.dev`） |
| CDN / 边缘节点 | 内容提前铺到全球机房，用户就近取 → 快 |
| HTTPS 证书 | 加密 + 身份证明；CF 自动签发（Google Trust Services）并自动续期 |
| 备案（ICP） | 中国大陆**境内**服务器的强制要求；用境外节点不需要 |
| SPA 回退 | 访问不存在的路径会返回首页（`200 + text/html`）—— 排查时别被骗 |

## 九、决策备忘（为什么是现在这样）

- **选 CF Pages 而非 GitHub Pages**：`github.io` 国内 DNS 污染，几乎打不开（GH Pages 只作海外镜像）
- **不选腾讯云 CloudBase**：默认域名被强制「测试域名」中间页 + 风控，不可投放（已实测否决）
- **不备案**：CF 海外节点可直连；若国内实测速度不满意，再评估备案（¥80–160 + 1–3 周）
- **字体/图标全部自托管**：外链 CDN 国内不可达且阻塞首屏（详见 `CLAUDE.md` 红线 #7）
- **域名成本策略**（2026-09-22 讨论）—— **不换域名**：旧域名一放弃，所有分享过的链接失效、且可能被抢注做垃圾站（对履历是负资产），代价远超省下的几十元。省钱正解：
  1. 先看**续费价**（不是首年价）→ 阿里云域名列表「续费」页
  2. ≤ ¥100/年 → **直接续 2–3 年**收工
  3. 偏高 → **转注册商到 Cloudflare Registrar**（成本价、无加价；DNS 已在 CF → 转移**零停机**；按 ICANN 规则转移时需续费一年，之后每年省）
  - 🚫 已否决：**每年换新域名薅首年 ¥1** —— 只适合玩票项目；本站是求职品牌入口，域名稳定即品牌资产。免费子域（`github.io` / `pages.dev`）同理不可取：国内不可达（正是买域名的原因）
