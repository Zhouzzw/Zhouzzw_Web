002

电控组负责人

RoboMaster 全向轮步兵机器人

基于 STM32G4 完成全向轮底盘运动学解算，实现复杂战场环境下的平滑移动与精准定位。 采用 FreeRTOS 设计多任务调度架构，设计双环 PID + 前馈控制策略提升云台轨迹跟踪精度。 基于 CAN 总线设计整车通信网络，保证控制指令低延迟传输。

成果

  • 底盘运动精度提升 30%，响应速度提升 25%
  • 高校联盟赛 3v3 (安徽站) 国家一等奖
  • 步兵对抗赛 国家二等奖
STM32G4 FreeRTOS PID + 前馈 CAN 总线 运动学解算
003

机械臂运控负责人

宇树 G1-D 机械臂 · Tesseract 双臂运动控制

上层仅下发一个三维目标位姿，由 Tesseract + Trac-IK/KDL 逆解与 OMPL 碰撞检测规划无碰撞路径， 经 Unitree SDK2 DDS（CRC32 + 全 35 关节锁定）50Hz 下发真机执行。 完成 VHACD 凸分解提速（单点规划 1.75s → 0.21~0.60s，约 5×）、双臂异步执行 （单 DDS publisher + 左右独立轨迹流互不阻塞），并叠加 200Hz 视觉伺服层 （卡尔曼预测 + Ruckig 平滑 + wdls 速度级 IK）追踪 30Hz 动态目标完成精定位抓卡。

成果

  • 双臂异步控制真机验证通过，左右臂规划执行互不阻塞
  • VHACD 凸分解将单点规划周期从 1.75s 降至 0.21~0.60s（约 5×）
  • 200Hz 视觉伺服闭环追踪动态目标，sim / real 同一份代码双模式运行
ROS2 Humble/Foxy Tesseract + OMPL 双臂异步控制 DDS 真机直驱 200Hz 视觉伺服
004

机械臂运控负责人

宇树 G1-D 机械臂 · Isaac RL 端到端到位控制

在 Isaac Lab 中用 rsl_rl PPO 训练 reaching 策略（4096 并行环境 + 步数驱动课程 + 域随机化），best 模型导出 ONNX 部署至机载 Jetson Orin NX，策略直接输出关节增量、 50Hz 直驱机械臂到位——不依赖 OMPL / IK 传统运动规划。目标按球域采样，训练与部署 共用同一份契约；到位判定为 TF 真实位姿连续 3 拍命中（位置 < 3cm 且姿态 < 5°）。

成果

  • 云端 50k 全量训练完成，到位率 90.9% ≥ 90% 验收线
  • ONNX 策略 50Hz 直驱 NX 真机，无规划节点、链路短
  • /arm_move 真实位姿到位判定（位置 < 3cm 且姿态 < 5°）真机复验通过
Isaac Lab / rsl_rl 端到端强化学习 ONNX Runtime sim2real 域随机化 Python
