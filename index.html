About

让硬件听从算法的指挥

我是周子惟，武汉科技大学电子信息工程专业大二在读（荆楚卓越人才计划）。 RoboMaster 战队电控组负责人，主导串联腿平衡步兵和全向轮步兵两款机器人的 电控系统开发。从 STM32 底层驱动到 LQR 最优控制、从 FreeRTOS 实时调度到 MATLAB 动力学仿真，我享受让硬件听从算法的过程。

Wuhan University of Science & Technology · Class of 2028

Core Skills

每一个决定都经过验证

  • 001

    单片机开发

    精通 STM32 / ESP32 / MSP-M0 系列单片机开发，熟练运用 FreeRTOS 实时操作系统构建多任务调度架构。

  • 002

    控制算法

    从双环 PID 到 LQR 最优控制、VMC 虚拟模型控制、MPC 模型预测控制，结合卡尔曼滤波实现稳定精准的机器人控制。

  • 003

    仿真与建模

    MATLAB / Simulink 动力学建模与仿真验证，数据拟合与分析，缩短实车调试周期约 30%。

  • 004

    外设与通信

    UART / IIC / SPI / CAN 总线协议开发，设计整车 CAN 通信网络，保证控制指令低延迟稳定传输。
